# Programa Trilhas Inova - Repositório de Desafios

## Descrição

Este repositório contém todos os desafios que enfrentei durante minha participação no **Programa Trilhas Inova**, uma iniciativa do governo do Maranhão focada em capacitar desenvolvedores back-end. Ao longo do programa, tive a oportunidade de aprimorar minhas habilidades em Node.js, bancos de dados, e desenvolvimento back-end, aplicando o conhecimento adquirido em projetos práticos.

## Estrutura do Repositório

- **Desafios**: Cada pasta neste repositório representa um desafio ou projeto realizado durante o programa. As soluções estão organizadas para facilitar a navegação e o entendimento do código.

## Tecnologias Utilizadas

- **Node.js**
- **Express.js**
- **MySQL**
- **JavaScript (ES6+)**
- **Git e GitHub**

## Minha Jornada

O **Programa Trilhas Inova** foi uma experiência transformadora que me permitiu consolidar minha base em desenvolvimento back-end. Ao longo do programa, apliquei o conhecimento teórico em situações práticas, desenvolvendo projetos que simulavam demandas reais do mercado de tecnologia.
